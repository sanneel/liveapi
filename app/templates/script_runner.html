Option 2 — install it yourself now

Works today, while the IT ticket is pending.

Download ZIP
  1. Download the ZIP above and unzip it somewhere permanent — not Downloads, and don't move or delete the folder afterwards. Chrome loads it from that path on every launch.
  2. Open a new tab and go to chrome://extensions (type it — Chrome blocks links to chrome:// pages).
  3. Turn on Developer mode, top right.
  4. Click Load unpacked and pick the unzipped folder.
  5. On the new Jugabet Script Runner card, click Details → Extension options, add this origin, and click Allow when Chrome asks:
    {{ crm_origin_pattern }}
  6. Reload this CRM tab.

One catch. Chrome nags about developer-mode extensions on every launch and can switch them off. If the Run in backoffice button disappears, that is why — re-enable it at chrome://extensions. It is the reason Option 1 is worth the ticket.

Using it

What changes once it is installed.

  1. Generate a script as usual, on Optimization or AI.
  2. Press Run in backoffice. The extension's toolbar icon badges the number of queued scripts.
  3. Make sure a logged-in backoffice tab is open, then open the extension popup and press Run.
  4. Read the log in the popup. Created JRN-… ids are pulled out and shown as chips.

Two things that are expected, not faults: Chrome shows a "started debugging this browser" bar while a script runs — that is how the script gets to run in the page exactly as a console paste would, and it clears when the run ends. And Copy script is still on every card; it stays as the fallback whenever a run misbehaves.

Nothing about how scripts are built changes. Verification still happens before a script exists, the extension never builds a payload, and every line the script logs — refusals included — is shown verbatim. A run that stopped early looks stopped.
