What the script creates

In one paste, in this order: reserves a promotion-display id and a journey id → copies the promo page's content and front templates to fresh ids → creates and saves the email content → creates the journey draft (external source → promotion → deposit → freebet → email) already pointing at that email → creates and saves the promo page draft → uploads the promo page's six content files to S3.

The promo page is linked to this run's journey entry activity, and every activity id in the journey is regenerated so it's a clean graph rather than a copy.

No images are uploaded — the copied template already carries the captured background, so there are no file pickers.
