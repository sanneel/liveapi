What this builds

One journey carrying the channels you tick, in order, with the splits and waits you ask for:

segment → NC → [wait] → [split] → pop-up → [wait] → [split]
        → email → [wait] → [split] → SMS → end

Where each input comes from — nothing else is consulted:

  • The chain shape — your ticks, verbatim.
  • Every word of copy — the sheet, read by row label.
  • Link, date, journey name — the sheet's Link / Start date / Event rows.
  • The journey body — captured nodes, cloned with fresh ids.
