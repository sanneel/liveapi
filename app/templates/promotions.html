Create randomizer

Prize slices, copy, routed journeys and segment all come from the captured template — only the date changes per run. Sport Wheel of Fortune clones its own visual content per wheel, so editing one wheel's artwork never rewrites another. Weights, journeys and prize copy can still be overridden under Advanced.

Type
Promo date(s)

Pick a date from the calendar and click Add — repeat for as many promos as you want. Each date becomes one randomizer, all created in one paste.

Days

Window length (applied to every date). Defaults per type (Scratch = 2).

Weights

Space-separated, in prize order. Must match the template's prize count.

Journeys

Space-separated routed journey ids, in prize order. Leave blank to keep the template's.

Prize copy override (Sport WOF only — rarely needed)

All seven slices ship their baked copy by default — leave blank. To rewrite a slice, add a line N English Spanish (tab-separated, wheel order); for all seven, paste seven lines with no numbers. A build where any slice would show its journey's internal name to players is refused.

The script creates the randomizer draft then fills it. Set PREVIEW=true at the top to inspect the request bodies before sending.

Welcome Pack — 1st Deposit / Aff

One affiliate promo code → up to four drafts: JBCL and FTCL (PMCL), each normal and boosted.

A–Z, 0–9, - and _, 3–32 characters. Several codes: separate with commas (the JBCL source carries two).

Boosted is the same journey plus the extra freebet after the deposit detector — 1.000 CLP on FTCL, 1.500 CLP on JBCL. One run builds one draft: each inherits its own source's promotion, so pick the one you are actually publishing.

Clones the four hand-maintained source drafts (FTCL 657225/657226, JBCL 657229/657230) live at paste time, swaps the promo code in both storages and regenerates every id. Creates drafts only.

Before you publish

This script cannot duplicate a promotion — the backoffice mints a new one per copy through calls we have never captured.

So every draft it creates points at its source's promotion, and therefore at the source's /services/promo/promotion/<id> link in each SMS, notification and pop-up. The script lists the inherited promotion per draft when it finishes. Re-point them by hand before anything goes live.
